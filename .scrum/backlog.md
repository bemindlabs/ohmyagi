## 1. Vision

> ### "เมื่อไม่ได้อยู่ในองค์กรใดแล้ว ก็ยังมี agi agent ที่ช่วยงานได้อยู่"
> **ความสามารถที่อยู่กับตัวคน ไม่ใช่กับองค์กร**

om-agi คือ **CLI ที่สร้าง agi agent ออกมาทำงาน — สร้างกี่ตัวก็ได้** (D-015)
แต่ละตัวเป็น **git repo ของตัวเอง** · **ทำงานด้วยตัวเองได้** (รันเองได้ + ลงมือเองได้) · **คุยกันได้ผ่าน A2A** (D-016)
และจำสิ่งที่เจ้าของ ***ทำ*** ไม่ใช่สิ่งที่พิมพ์ · **`git clone` ไปที่ไหนก็ยังเป็นตัวเดิม**

```
projects/om-agi/              ← engine — โปรแกรม (Bun)
agents/<name>/                ← ตัวตน — 1 agent 1 repo (D-013)
   soul/ memory/ consent/     ← ใน git · Markdown/JSON ที่มนุษย์อ่านออก = แหล่งความจริง
   actions/                   ← ใน git · action ที่สกัดแล้ว
   .dagi/                     ← ไม่เข้า git · ลบแล้วสร้างใหม่ได้ (observer ดิบ · index · ledger · adapter)
~/.local/share/om-agi/<name>/personal/   ← นอก repo · ข้อมูลส่วนตัว (D-014)

  ohmyagi setup / new <name>  →  สร้าง agent (repo + soul)
  ohmyagi turn · triggers tick →  agent ทำงาน (ทำเองตามเวลาได้ แต่เสนอเท่านั้น)  →  ExecBackend  →  claude | codex | ollama | …
       agent A  ⇄  A2A 1.0.0 (มาตรฐานเปิด)  ⇄  agent B / agent ของ bwoc / ใครก็ได้
```

### Positioning (D-019)
**Grok Bot ของ xAI (ส.ค. 2026) ทำสิ่งเดียวกันเกือบทุกข้อ** — memory · autonomy · runtime ของตัวเอง

**ไม่แข่งเรื่องความฉลาด — แข่งเรื่องความเป็นเจ้าของ**

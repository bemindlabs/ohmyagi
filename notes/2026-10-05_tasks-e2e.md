## Limits, said plainly

- **Resume is by hand.** A task whose runner died is shown `interrupted` everywhere (CLI, `/api/state`, the
  page's Resume button); nothing resumes it on its own — there is no daemon (D-054). Its browser starts fresh on
  resume (a clean profile, D-151): a page it had open is gone.
- **Token budgets on claude are mostly turn budgets**: claude counts its cache reads as input (~80,000 a turn).
- **The step that runs when a limit is reached finishes**; its turn's own timeout is at most the minutes left.
- **Telegram, A2A and triggers** (D-154's later channels) are not wired: a trigger's turn is held at level 1 and
  cannot start a task; A2A only reaches `turn`.

### Limits, said plainly

- **The release key is the owner's**, like the task's token: it is in the browser record (600, state root).
  Anything running as the owner — a cloud turn's shell at write/run 2 among them — could read it and write a
  release, as it could already write an approval into the proposal store (D-042's limit). What it closes is
  everything else: a file that did not come from the key's holder, a yes for another action, a second use.
- **An approval binds the step, not a value**: approving "type into the password field" lets that typing
  happen once with whatever value the model types; the value is never shown to the owner (it is never
  recorded). No credential store exists yet (D-150, D-156).
- **A confirm the page shows is a second question.** Accepting any page `confirm` is held (round 3 of PR #19),
  so "Delete" behind a confirm asks twice. Each answer is bound to its own action.
- **A held action waits inside the step's turn**: claude's per-server MCP `timeout` is the wait plus two
  minutes, and the step's turn timeout grows by one wait. A step that is held several times can run out of
  its own timeout.
- **Expiry is enforced on both sides**: the container stops waiting 5 s after `expiresAt`; the CLI and the API
  refuse an answer after it; the runner records the expiry so a late answer finds it decided.

# Getting help

- **Something does not work** — run `ohmyagi doctor` first: it checks each backend, the local model, the stores
  and the paths, and says what to fix. If that does not explain it,
  [open a bug report](https://github.com/bemindlabs/ohmyagi/issues/new/choose).
- **How do I …** — `ohmyagi help` lists every command with its flags; the [README](README.md) walks through
  setting up an agent; `docs/` holds the architecture decisions and the demo.
- **A security problem** — privately, as [SECURITY.md](SECURITY.md) describes. Never in an issue.

Oh My AGI is a 0.x maintained by a small team: answers come when they can, and the newest release is the one
that gets fixes.

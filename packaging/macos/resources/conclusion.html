Installed

Terminal should now be showing ohmyagi setup. If it is not, open Terminal and type it.

For a fully local agent, install Ollama and pull a model first; setup lists the models it finds.

To remove: sudo rm /usr/local/bin/ohmyagi /usr/local/bin/om-agi && sudo pkgutil --forget tech.bemind.ohmyagi. Your agents and their data are not touched by removing the program — ohmyagi erase is how a subject's data goes.

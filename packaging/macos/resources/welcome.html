Oh My AGI

A command-line tool that builds AI agents you own: each one has its own identity, lives in its own git repository, and runs on a local model or on the AI CLIs you already use.

This installs one file, /usr/local/bin/ohmyagi (and om-agi as another name for it). No background service, no data, no network access during installation.

When it finishes, Terminal opens with ohmyagi setup, which walks you through a first agent one question at a time. You can close it and run ohmyagi setup later.
